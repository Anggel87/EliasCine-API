1. Reglas generales de la API

Entrada

  • Los cuerpos se envían como application/json.
  • Los ids se envían en la URL y deben ser enteros positivos.
  • En listas: skip es opcional, mínimo 0.
  • En listas: limit es opcional, de 1 a 100; valor predeterminado 100.

Salida

  • Las listas devuelven un arreglo JSON.
  • GET individual, POST y PUT devuelven un objeto JSON.
  • DELETE devuelve { message, id }.
  • La propiedad password nunca aparece en respuestas.

2. Operaciones disponibles para cada recurso

MétodoRutaCuerpoRespuesta exitosa
GET/api/{recurso}Ninguno. Query opcional: skip, limit.200: arreglo de registros.
GET/api/{recurso}/{id}Ninguno. id obligatorio en URL.200: registro solicitado.
POST/api/{recurso}Campos obligatorios y opcionales según la tabla del recurso.201: registro creado con id.
PUT/api/{recurso}/{id}Se envía el cuerpo completo del recurso.200: registro actualizado.
DELETE/api/{recurso}/{id}Ninguno. id obligatorio en URL.200: confirmación de eliminación.
