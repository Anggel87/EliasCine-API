1. Ejecución

docker compose up --build -d
docker compose run --rm api python -m app.seed
  • El contenedor temporal ejecuta app.seed contra MySQL del servicio mysql.
  • Se puede ejecutar varias veces: busca registros existentes antes de insertar.
  • Para borrar todo y volver a iniciar desde cero: docker compose down -v.

5. Salas y asientos

Cada sala recibe seis asientos:

Sala IMAX     → A1, A2, B1, B2, C1, C2
Sala Marvel 2D → A1, A2, B1, B2, C1, C2

La función selecciona el asiento A1 de la sala correspondiente para crear el boleto demo.
